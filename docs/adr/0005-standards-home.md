# ADR-0005 — Standards home for the US mDL ZK profile

Status: accepted 2026-09-01

## Context
No standards body has a US mDL profile for ZK presentation. PSE zkID already has ETSI TS 119 476-2 and ISO channels for EU work. Spec section 10 decision 5.

## Decision
Contribute the AAMVA / US mDL profile through PSE zkID's existing channels rather than open a new track.

## Consequences
PSE zkID co-authors; the profile is an M9 deliverable alongside the pilot report.
