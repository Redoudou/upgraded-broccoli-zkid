# ADR-0004 — First venue is age-gated retail, not hotel

Status: accepted 2026-09-01

## Context
Hotels must often record name and address; an age-only proof cannot satisfy that. Spec section 10 decision 4.

## Decision
Pilot primary sites are two age-gated retail locations. One hotel site is included as the hard case only, with the plastic-card path remaining primary there.

## Consequences
The legal memo (M7) targets the retail obligation first. Hotel findings go in the report as open questions.
