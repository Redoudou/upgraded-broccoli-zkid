# Component research index

Each file in this directory is a research note on one thing Green Light assembles rather than builds: what it is, where it lives (URL, licence, version seen), how the spec and plan use it, how to build or call it, its maturity and risks, and the questions to put to its owner. Every note was written on 2026-09-01 and independently re-verified against live sources on 2026-09-02; every claim carries a source link and anything not confirmed is marked [unverified]. The table below is the one-line summary; the discrepancies these notes surfaced against SPEC.md are collected in [../SPEC-NOTES.md](../SPEC-NOTES.md), and the partner questions are copied into [../PARTNERS.md](../PARTNERS.md).
